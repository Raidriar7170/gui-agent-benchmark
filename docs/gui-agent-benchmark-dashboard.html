What the run shows

Environment readiness can be separated from task success.

Capture coverage reached 10/10, so missing evidence is no longer the main explanation for failures.

Failures cluster around GUI interaction primitives.

Dropdown commit, table selection, modal confirmation, pagination, sorting, multi-select, validation recovery, and upload completion remain brittle.

Solvability is explicitly checked.

The scripted oracle baseline validates all 10 deterministic tasks through the same UI and judge path.

Evidence boundary: expanded step traces are derived timeline attributions, not raw UI-TARS action transcripts. Current claims are qualitative, not leaderboard-style model rankings.

Why This Is Resume-Relevant

The project is strongest as an agent reliability artifact: it shows how to turn ambiguous GUI-agent failures into a reviewable evidence chain with validators and honest scope boundaries.
